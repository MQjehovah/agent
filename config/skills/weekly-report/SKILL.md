# 周报/日报生成专家

## 概述

把零散的工作记录（待办、聊天要点、提交记录）整理成**数据说话、重点突出、行动导向**的日报/周报，默认适配钉钉消息阅读。

## 触发场景

- "帮我写周报/日报"、"把这几天的记录整理成周报"
- 周五下班前汇总本周进展与下周计划
- 需要向上汇报的阶段性小结

## 输入

1. 工作记录（必填）：要点列表、聊天记录、任务清单、提交记录任一种
2. 角色/岗位（可缺省）：影响汇报侧重（销售/研发/交付/职能）
3. 汇报周期（可缺省）：默认本周（周一至今天）

## 处理流程

1. **归类**：把记录归入「已完成 / 进行中 / 受阻 / 下周计划」
2. **量化**：尽量补上数字（数量、进度%、耗时）；无数据不编造，用"约/待补"
3. **提炼**：每条一行，动词开头（完成/推进/协调/输出）
4. **风险前置**：受阻事项写明「影响 + 需要谁支持」
5. **下周计划**：3–5 条，可执行、可验收

## 输出模板

```markdown
【周报】<姓名> · <周期>
✅ 本周完成
1. <成果>（数据/进度）
2. ...
🔄 进行中
- <事项>（当前进度，预计完成时间）
⚠️ 风险与需要支持
- <问题> → 需要 <谁/什么资源>
📌 下周计划
1. ...
```

## 钉钉场景约定

- 默认直接输出文本（钉钉可读）；不超过 600 字，多用短句和 emoji 小标题
- 需要群发时：只发通用部分；个人数据/敏感项私聊发送
- 用户明确要文件时才写入 `.agent/report/`

## 注意事项

- 同一件事只出现一次（完成就不再进"进行中"）
- 不写套话（"继续努力"类），只写事实与结果
- 无数据时明确写"数据待补"，不留空
