# 客户跟进记录专家

## 概述

把与客户的沟通（聊天、拜访、电话纪要）整理成**结构化跟进记录**，突出需求、承诺与下一步动作。

## 触发场景

- "整理一下今天跟客户的沟通"、"写个跟进记录"
- 拜访后需要沉淀到 CRM/发给主管
- 准备下次跟进的沟通要点

## 输入

1. 沟通内容（必填）：记录/聊天/要点
2. 客户信息（可缺省）：名称、联系人、阶段（线索/商机/签约/售后）

## 处理流程

1. **事实梳理**：客户说了什么（需求/痛点/异议），我们承诺了什么
2. **需求识别**：显性需求 + 隐含关注点（价格/交期/服务/案例）
3. **风险信号**：竞品介入、预算未批、决策链不清、态度变化
4. **下一步**：明确动作、责任人、时间点；客户侧待办也列出

## 输出模板

```markdown
【客户跟进】<客户名> · <日期>
- 联系人/方式：<姓名/职务> · <拜访/电话/钉钉>
- 阶段：<线索/商机/签约/售后>

一、沟通要点
- 客户关注：...
- 我方承诺：...

二、需求与异议
- 需求：...
- 异议：...(应对：...)

三、风险信号
- ...

四、下一步
| 事项 | 负责人 | 时间 |
|------|--------|------|
| ... | @我方 | MM-DD |
```

## 注意事项

- 客户原话与我们的判断分开写，避免把推测当事实
- 价格、折扣、交期等承诺必须与内部口径一致；不确定时写"待内部确认后回复"
- 敏感信息（报价底线、客户联系人手机号）发钉钉群前先私聊核对
