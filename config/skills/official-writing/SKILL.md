# 公文与通知写作专家

## 概述

撰写公司内部通知、公告、函件等正式文书，做到**结构规范、措辞得体、要点无歧义**。

## 触发场景

- "写一份关于 XX 的通知"、"发个公告"
- 制度调整、时间变更、活动安排需要正式发文
- 对外函件（合作、催办、致谢）

## 文种选择

| 文种 | 用途 | 语气 |
|------|------|------|
| 通知 | 要求执行/知悉的事项 | 明确、指令性 |
| 公告 | 面向全员的重要事项 | 庄重、简洁 |
| 通报 | 情况说明与警示 | 客观、有结论 |
| 函 | 对外沟通 | 礼貌、留有余地 |
| 会议纪要 | 见 meeting-minutes 技能 | 中性、事实导向 |

## 结构（通知类）

1. **标题**：关于<事项>的通知
2. **主送**：各部门/全体员工（或指定对象）
3. **正文**：背景一句 → 具体安排（时间/地点/对象/操作，分条）→ 要求（截止、责任人）
4. **落款**：发文部门 + 日期

## 写作要求

- 一事一文；分条用"一、二、三"
- 时间写全（YYYY-MM-DD HH:mm），地点写具体（楼栋/会议室/线上链接）
- 涉及执行的必须写明：谁、在什么时候、做什么、找谁咨询
- 不用口语、感叹号；不用"尽快"这类模糊词，改为具体截止时间

## 输出模板

```markdown
关于<事项>的通知

<主送对象>：

一、<背景/依据>（一句带过）
二、<具体安排>
  1. 时间：2026-XX-XX（周X）14:00
  2. 地点/方式：...
  3. 参加/涉及：...
三、<要求>：请于 XX 前完成 XX；如有疑问联系 <部门/人>（钉钉同名）。

<发文部门>
2026-XX-XX
```

## 注意事项

- 敏感事项（人事、处罚）先提示需相应负责人审核后再发
- 对外函件不透露内部信息；署名用公司/部门全称
- 发布到钉钉群前，确认发送范围；重要通知建议加"请各部门负责人确认收到"
