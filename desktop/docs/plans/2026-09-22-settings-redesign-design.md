# 设置界面优化设计（Dashboard 员工端）

- 日期：2026-09-22
- 范围：`dashboard` 仓库渲染层（`src/views/SettingsView.vue` 重写 + 必要样式）
- 视觉方向：**A 克制专业风**（现代控制台质感，与 agent 端气质一致）

## 目标

把设置页从「一列 12 项长表单」改造为**分区卡片 + 吸底操作条**，并补齐企业账号认证区与操作反馈。

## 非目标（明确不动）

- 配置项本身、`%APPDATA%/dashboard/config.json` 存储位置
- 主进程逻辑：`electron/main/store.ts`、`identity.ts`、`upstream.ts`、`usage.ts`
- 其他页面与全局主题变量定义
- 不新增依赖（继续用 Element Plus + 现有图标）

## 布局

单页滚动，四张分区卡片 + 一张「关于」卡片，页面底部**吸底操作条**。

### 分区 1：账号与企业认证

- **账号卡**
  - 左侧：44px 首字母头像（品牌渐变）+ 姓名 / 工号 / 部门 / 角色
  - 右侧按钮组：
    - 未登录 → 主按钮「登录企业账号」+ 说明（由主进程打开系统浏览器，凭证只保留在主进程）
    - 已登录 → 绿色状态点 +「已登录」+ 次要描边按钮「重新登录」「退出登录」
- **OIDC 配置**：Issuer / Client ID / Client Secret，顶部标签 + 字段说明（留空则读环境变量 `OIDC_ISSUER` / `OIDC_CLIENT_SECRET`）

> 现状缺陷：`doSsoLogin()` 已实现但模板未渲染按钮，设置页无法登录/重新登录 —— 本次补齐。

### 分区 2：服务地址

- 5 行地址：Agent 执行引擎 / RAG 知识库 / 能力市场 / 算力网关 / Router Admin
- 1 行 Internal Secret（password 输入）
- 每行结构：顶部标签 + 输入框（占满）+ 右侧**状态徽标**
  - 徽标四态：未测（灰）/ 探测中（转圈）/ 正常（绿，悬停显示耗时）/ 失败（红，悬停显示原因）
- 探测 5 个服务并行执行；「测试连通性」按钮在吸底操作条，点击时**先保存**再探测（保证测的是当前填写值）

### 分区 3：本地模式

- 默认模型（文本）
- 默认工作区：路径省略显示 + 「选择目录」按钮（复用现有 `localagent:workspace:pick` IPC）

### 分区 4：外观

- 主题：两个**预览块**（深色 / 浅色，各含迷你界面示意）替代原单选框；点击**即时生效并持久化**

### 关于

- 版本 + 各系统入口说明；修正已过时的一句：「用量视图见左侧导航」→「用量与账号信息见个人中心」

## 交互规约

| 项 | 规则 |
|---|---|
| 未保存提示 | 进入页面记录快照；有差异时底栏显示琥珀色圆点 +「有未保存的修改」；保存成功后消失 |
| 保存 | 按钮 loading 态；成功 `ElMessage.success`，失败 `ElMessage.error` 并保留表单内容 |
| 地址校验 | 必须 `http(s)://` 开头；不合法 → 高亮该行 + 行内错误文案，**阻止保存** |
| 主题 | 即时生效项，单独持久化，不计入「未保存」状态 |
| 退出登录 | 二次确认；成功后清空对话并回落到登录门（沿用现有 `settings.logout()` 行为） |
| 登录/重新登录 | 失败时给出主进程返回的错误文案，不吞错 |

## 视觉规范

- 颜色一律使用 Element Plus 变量（`--el-*`）与现有 app 变量，保证深/浅两套主题均可读，不写死颜色
- **卡片**：圆角 14px、内边距 18–20px、卡片间距 14px；标题行 = 图标 16px + 标题 15px/600 + 说明 12.5px/secondary
- **表单**：`label-position="top"`；输入框统一默认尺寸；字段说明 12px/secondary
- **账号卡**：头像 44px/圆角 12px/品牌渐变；状态点 7px 圆点；按钮组右对齐
- **服务行**：`display:grid; grid-template-columns: 1fr auto; gap:10px`；徽标固定宽度右对齐，保证 5 行纵向对齐
- **吸底操作条**：`position: sticky; bottom: 0` + `backdrop-filter: blur(8px)` + 1px 上边框；左侧未保存提示，右侧「测试连通性」「保存」
- **动效**：仅 hover/focus 的 `transition .15s`，不做入场动画

## 验证

- 静态：`npm run typecheck`（node + web）、`npm run build`（electron-vite）、`npm test`（现有 203 用例）
- 手动：登录 / 重新登录 / 退出；保存与未保存提示；测试连通性（含失败态与未测态）；选择工作区；深浅主题切换
